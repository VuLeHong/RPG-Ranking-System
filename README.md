# Management System Website

This is a web application built for managing tasks, user profiles, project details, rankings, and comparisons. It leverages **Express** for the backend, **React** for the frontend, and **MongoDB** for the database to provide a seamless experience.

## Features

- **Login Page**: Secure authentication for users.
- **Profile Page**: Display and analyst user profile information and stats.
- **Task Management Page**: Show and update tasks.
- **Ranking Page**: Compare user rankings and achievements.
- **Project Management Page**: Overview of all projects, including details.
- **Comparison System**: Ability to compare rankings between users stats.

## Technologies Used

- **Frontend**: React
- **Backend**: Express
- **Database**: MongoDB
